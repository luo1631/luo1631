# Hi，我是 luo1631👋

喜欢写软件、研究 AI，也爱琢磨界面怎么设计。遇到陌生的东西，我习惯先从一堆信息里理出几条关键关系，再挑自己最拿不准的一条，动手试试。

## 我怎么做东西

- **拆系统。** 我喜欢顺着一次点击往下追，看界面怎么变、数据经过哪几个模块、最后存在哪里。理清这条线，也就更容易判断一个功能该加在哪一层。
- **和 AI 协作。** 我会把目标、限制和验收标准讲清楚，给模型留出自己选工具、提方案的空间。我挺喜欢它能反驳我，尤其是它能拿出一个更好的做法时。
- **琢磨交互。** 我喜欢有氛围的画面，也在意第一次打开界面的人能不能一眼看出哪里能点。有时让背景安静下来，一个原本容易错过的入口就显眼了。

平时用得比较多的是 `TypeScript`、`Python`、`React`、`Node.js` 和 `Electron`
